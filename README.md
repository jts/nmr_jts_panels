Code to generate my figure panels for the NMR T2T paper. The main driver is `bin/run.sh` and should be pointed to the dropbox path:

```
bin/run.sh /path/to/dropbox/NMR_T2T
```

Requires various python and R packages, and my modified version of ModDotPlot (found here: https://github.com/jts/ModDotPlotMod/) to be installed.
